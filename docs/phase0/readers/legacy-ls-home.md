## 3. Discrepancies and corrections to the brief (for `docs/plan.md`)

1. **06 §1 JS weight at the baseline:** 47,682 B at `9b78785` (not 47,112, which is `fe4b056`); gzip 15.4 KB. Cosmetic; the budget statement stays valid (`wc -c public/js/*.js`).

Cite `9b78785` with these lines from now on.
3. **06 §9 quirk 1 is moot at `9b78785`:** a backend `Non gestito` never reaches `renderShipment` (`tracking.js:226-227`), so the "empty progress bar" can only appear in demo mode (`demoShipment`, `tracking.js:75`, an event with status `NON_GESTITO`) or if a future answer embeds it in `events[]`. TRK-01 tests should assert the neutral message, not an empty bar.
4. **06 §3.1/§3.2 `/grazie/` and 404 "no Open Graph tags":** they carry the partial's `og:site_name`/`og:locale` (`partials/head.html:13-14`). The PUB-01 parity test must expect those two on every page.
5. **06 §5.6 step 2 precision:** the 20,000-character body check applies to the `Content-Length` header and to url-encoded bodies only; a `multipart/form-data` body is not re-measured after the header check (`form.mjs:250-258`). The site's forms never send multipart (no `enctype`), so the monolith may accept url-encoded only, or keep multipart for parity (decide in the `/api/form` ADR).
6. **06 §5.6 `telefono` server limit:** read with max 30 (`form.mjs:56`) then regex `{6,20}` (`:33`); a 21-30 character value is rejected, not truncated to 20. The field table says only "regex".
7. **06 §6.8 misses Netlify behaviours the monolith must reproduce:** gzip/brotli compression of HTML/CSS/JS/SVG (the §1 gzip weights and PUB-10 assume it), `ETag`/304 revalidation for files without a `Cache-Control` rule, HTTP/2 + TLS, and serving `/404.html` **as a 200 page at its own URL** (it is a real file; §3.1 lists it in the inventory, so the PUB-01 walk must decide whether `/404.html` answers 200 or 404).
8. **06 §4.10 / §8.2 active-menu detail:** `data-nav="home"` exists only in the drawer (`partials/header.html:69`); the header buttons "Traccia" and "Preventivo gratuito" carry `data-nav="tracking"`/`"preventivo"` (`header.html:53-54`) and therefore get `aria-current="page"` on `/tracking/` and `/preventivo/`. The helper must apply the rule to every `data-nav` in the whole header partial (topbar links have none), and the drawer's auto-open (`main.js:79-80`) depends on `aria-current` being rendered inside `[data-drawer-group]`.
9. **06 §8.5 "Speculation rules"** proposes excluding private prefixes; that edits `partials/head.html:17` on all 26 pages, which PUB-01's allow-list (chapter 09) does not mention (also flagged by reader 06). Add it to the allow-list (see §7).
10. **06 §4.13 "Tabs without JS: panels stacked":** VERIFIED by CSS `[data-ready]` rules, but the home quick-tools tracking form has `required` on the code input (`public/index.html:192`), so an empty native GET is blocked by the browser; the `/tracking/` form too (`tracking/index.html:155`). Harmless; note for the no-JS E2E.

## 6. Risks and unknowns

* **PUB-01 byte parity vs a template engine:** Thymeleaf/AttoParser may re-serialise `<use …/>` (self-closing non-void), `<source>`/`<img>` void tags, `&#x27;` entities and attribute quoting. Define parity as normalised-DOM equality (parse legacy file and rendered page with the same parser, e.g. jsoup, compare after whitespace normalisation) and record any residual serialisation diff in the allow-list. Guard copied `<main>` blocks with `th:inline="none"` even though no `[[` exists today.
* **PUB-05 framework defaults:** Spring Security writes `Cache-Control: no-store`, `X-Frame-Options: DENY`, HSTS with `includeSubDomains` and no `Permissions-Policy`; the exact `_headers` set must be configured explicitly, and the `/fonts/**`, `/img/**`, `/*.png` cache rules must override the default no-store writer. Decide `SAMEORIGIN` (parity) vs `DENY` (stricter; `frame-ancestors 'self'` is in the CSP anyway).
* **PUB-04 routing:** Spring 6 no longer matches trailing slashes implicitly → explicit 301 `/zone` → `/zone/`; `/index.html` → `/`; `404.html` must be served without the framework's whitelabel page (inline CSS would break the CSP).
* **PUB-06/07 server port:** `servizi_extra[]` needs explicit binding (`getParameterValues`); the `Content-Length` 20,000 check and the `Accept` switch must be hand-written (content negotiation would 406); CSRF exemption + `Origin`/`Referer` check; the truncation → 422 change and decimal `numero` (quirk 5) need the ADR; `data_ritiro` UTC minimum (quirk 6) is client-side only.
* **PUB-08:** zone data lives in JS, HTML legends/tables and the SVG (`README.md:75-77`); `/zone/?cap=` without JS shows nothing specific (quirk 11 race with JS); Q-14 may change the times (ENH-10).
* **PUB-10:** compression, HTTP/2 and `ETag` are Netlify features; without them the gzip budgets and Lighthouse ≥ 95 are at risk. The 1.4 MB of OG PNGs and 1.6 MB of photos are never on the critical path (only the hero `<picture>`); keep `fetchpriority` and preloads.
* **TRK-01/TRK-04:** any non-2xx (incl. 429 from the rate limit) reads as "not found" (`tracking.js:181`); choose parity or a one-line change (treat 429/5xx as `error`), record it. **TRK-03:** never return `pod`; `tracking.js:134` would link it unchecked.
* **NFR-03:** `/privacy/` names Netlify and AWS SES; `/cookie/` promises no cookies; both change once the customer area sets a session cookie — keep public pages cookie-free so the cookie page stays true for `/`.
* **Q-31 copy items** (§7.3 of chapter 06) and **Q-29** (live URL inventory) are owner inputs; the `fe4b056`-era town lists and stats are unverified.
* **Unknowns:** today's `main` head of ls-home (clone has no `main`); how OG images were generated; CSP vs the SVG's internal `<style>` as `<img>`; SES identities/sandbox; whether the office wants `MAIL_TO` with several addresses (the app's outbox decides, EML-08).
